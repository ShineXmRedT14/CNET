# HOW TO INSTALL CNET
---
1. git clone https://github.com/ShineXmRedT14/CNET . ( or downoload zip in the . directory )
2. cd /CNET/Your Version/installer/
3. chmod +x ./cnetsh.sh
4. sudo ./cnetsh.sh
---
After you doing this you can easily use CNET library:

```c
#include <cnet.h>
#include <cnet_tcp.h>
#include <cnet_udp.h>
...
```
